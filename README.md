# iCON | Türk Hava Kurumu Üniversitesi Web Portalı

> **INNOVATION • CAREER • ORGANIZATION • NETWORK**  
> *"More Than A Club. Higher Ideas, Further Together."*

Türk Hava Kurumu Üniversitesi resmi öğrenci topluluğu **iCON** için modern, sinematik gece atmosferine ve cam efektlerine (glassmorphism) sahip interaktif web portalı.

---

## ✈️ Özellikler

- **Sinematik Havacılık & THKÜ Teması:** Gece aydınlatmalı havacılık pisti, hangar, tırmanan yolcu jeti ve ofis manzarasıyla tam uyumlu görsel atmosfer.
- **Glassmorphic Arayüz:** Gerçekçi cam efekti (`backdrop-filter: blur()`), parlak neon mavi vurgular ve 3D fare takip tilt animasyonları.
- **Duyarlı (Responsive) Çift Mimari:** 
  - **Masaüstü:** Sol tarafta kurumsal marka kimliği ve vizyon armaları; sağ tarafta interaktif aksiyon kartları.
  - **Mobil:** Akıcı ve dokunmatik uyumlu Link-in-Bio kart akışı.
- **İnteraktif Modallar:**
  - 👥 **Topluluğa Katıl:** THKÜ mühendislik ve havacılık bölümleri için çalışan başvuru/kayıt formu.
  - ⚙️ **Projelerimiz:** Otonom İHA Sistemleri, Uçuş Takip Portalı ve Havacılık Simülasyonu projeleri.
  - 📅 **Etkinliklerimiz:** "THKÜ Aviation & Innovation Summit '26" için canlı geri sayım sayacı.
  - 👥 **Ekiplerimiz:** AR-GE, Yazılım, Organizasyon, Medya ve Yönetim Kurulu tanıtımı.
  - ℹ️ **iCON Hakkında:** Misyon, vizyon ve topluluk istatistikleri.
- **Atmosferik Ses Kontrolü:** Web Audio API ile sentezlenen dinlendirici kabin esintisi ve ses efektleri.
- **Sosyal Medya:** Instagram, LinkedIn ve TikTok hızlı bağlantıları.

---

## 🛠️ Teknolojiler

- **HTML5 & CSS3:** Modern CSS değişkenleri, Vanilla Glassmorphism, Flexbox & Grid.
- **JavaScript (ES6+):** Modallar, Web Audio API, form doğrulama, dinamik sayaç ve parçacık motoru.
- **Vite:** Hızlı ve modern geliştirme ortamı.

---

## 🚀 Başlangıç

### Gereksinimler
- Node.js (v18+)
- npm

### Kurulum

```bash
# Bağımlılıkları yükleyin
npm install

# Geliştirici sunucusunu başlatın
npm run dev

# Yayına hazır derleme alın
npm run build
```
